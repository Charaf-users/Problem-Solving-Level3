C++ Course Level 3: Algorithms and Problem Solving

This repository gathers all my solutions to the exercises and problems from Course 7: الخوارزميات (C++ Algorithms - Level 3).

The goal is to document my understanding and application of fundamental algorithms, matrix manipulation techniques, string processing, and file operations.

📚 Topics and Concepts Covered

The 51 problems in this course are divided into several main modules:

1. Matrix Manipulation (Problems 1–20)

This section focuses on basic operations with 3x3 two-dimensional arrays (matrices).

Creation and Filling: Fill a matrix with random numbers or ordered numbers.

Calculations and Sums: Calculate the sum of each row, each column, or the total sum of the matrix.

Matrix Operations: Perform matrix transposition and multiplication.

Analysis and Verification:

Check if a matrix is an identity matrix, scalar, palindrome, or sparse.

Compare matrices for equality or similarity.

Data Searching: Find the minimum/maximum value, count a specific number, or verify its existence.

2. Algorithms (Problems 21–22)

Fibonacci Sequence: Implementation using both iterative loops and recursion.

3. String Manipulation (Problems 23–44)

This section covers a wide range of text-processing techniques.

Case Modification:

Capitalize or lowercase the first letter of each word.

Convert an entire string to uppercase or lowercase.

Invert the case of each character.

Counting:

Count uppercase/lowercase letters, a specific character (case-sensitive or not), vowels, and total words.

Splitting and Formatting (Parsing):

Split: Divide a string into words stored in a vector.

Trim: Remove spaces at the beginning, end, or both sides of a string.

Join: Combine a vector or array of strings into one string.

Word Manipulation:

Reverse the order of words in a sentence.

Replace words (using the built-in replace function or a custom implementation).

Remove all punctuation marks from a string.

4. Data and File Management (Problems 45–51)

This section applies previous concepts to build a mini client management system for a bank.

Data Conversion:

Convert a client record (struct) into a text line (CSV-like format).

Convert a text line back into a client record (struct).

CRUD Operations on Files:

Create: Add new clients to a file (Clients.txt).

Read: Display all clients from the file and find a client by account number.

Update: Modify a client’s information.

Delete: Remove a client from the file based on their account number.
